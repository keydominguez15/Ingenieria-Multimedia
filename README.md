# Taller de Node.js con Express y Supabase

Este proyecto es una práctica de desarrollo backend utilizando **Node.js**, **Express** para la gestión de rutas y peticiones,
y **Supabase** como base de datos en la nube. Incluye sistema de encriptación de contraseñas.

## Tecnologías utilizadas
* **Node.js** - Entorno de ejecución para JavaScript.
* **Express** - Framework web para Node.js.
* **Supabase** - Base de datos PostgreSQL y backend como servicio.
* **Bcrypt** - Librería para el hash y seguridad de contraseñas.
